# TPI - WhatsApp — Trabajo Práctico Integrador 

## Descripción

Aplicación de chat en tiempo real, similar a WhatsApp, desarrollada como Trabajo
Práctico Integrador de las materias Desarrollo de Aplicaciones Informáticas y
Proyecto de Producción.

Permite a los usuarios registrarse, iniciar sesión, ver su lista de contactos y
chats (individuales y grupales), crear chats nuevos a partir del mail de otro
usuario, crear grupos con múltiples participantes, y comunicarse en tiempo real
mediante WebSockets (Socket.IO), con persistencia del historial en una base de
datos MySQL.

## Tecnologías utilizadas

- **Frontend:** Next.js (App Router) + React
- **Backend:** Node.js + Express
- **Base de datos:** MySQL
- **Comunicación en tiempo real:** Socket.IO
